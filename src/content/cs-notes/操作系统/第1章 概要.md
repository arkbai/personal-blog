## 概念
1. 用户观点：作为用户与计算机硬件之间的接口，最基本的系统软件
	- 用户接口：1. 联机用户接口（命令行） 2. 脱机命令接口（批处理） 3. 图形用户接口GUI
	- 程序接口：一组**系统调用**
	<img src="images/QQ_1785898193094.png" width="159">
2. 资源管理观点：对系统资源进行控制、调度、分配、回收
	- 处理器管理
	- 存储器管理
	- I/O设备管理
	- 文件管理
3. 虚拟机观点：裸机+软件扩展
## 分类与发展
1. 手工操作系统
	- 人工
	- 脱机I/O：I/O操作由外围机完成
2. 单批道处理操作系统：出现操作系统雏形，由监督程序自动运行作业
3. 多批道处理操作系统：使用中断技术，多道程序共享计算机资源
		- 优点：资源利用率高，系统吞吐量大 / 缺点：平均周转时间长，无交互能力
4. 分时操作系统：操作系统把CPU运行时间分成时间片，轮流分给多用户使用
	- <u>中断功能、时钟、页式存储方式</u>；
	- **交互性**、多路性、独立性、及时性
5. 实时操作系统：优先响应紧急任务，使其不进行时间片排队
	- 确定性，可靠性，时效性
	- eg:温度控制系统，流水线系统，机票订购系统
------
其他类型：
	1. 微机操作系统
	2. 网络操作系统
	3. 分布式操作系统
	4. 嵌入式操作系统
## 特征
1. **共享**
	- 互斥共享方式
	- 同时共享方式（逻辑上，宏观上同时）
2. **虚拟**：把一个物理上的实体变为若干个逻辑上的对应物
	- 时分复用--分时操作系统
	- 空分复用--虚拟存储器
3. **并发**：<u>进程</u>实现了并发活动
> 并行-多个事件同时发生
> 并发-微观上事件交替发生，同一时间间隔内发生
4. **异步** 
> 概念：在多道程序环境下，允许多个程序并发执行，但由于资源有限，进程的执行不是一贯到底的，而是走走停停的，以不可预知的速度向前推进。
> 只有系统拥有并发性，才有可能导致异步性。

## 操作系统运行环境
### 1、操作系统内核
> 内核：操作系统最靠近硬件、最核心的部分，内核程序组成操作系统内核

- 内核功能：
	1. 时钟管理
	2. 中断机制
	3. 原语：若干条不可切割的指令
	4. 系统资源管理：进程、存储器、设备的管理
- 处理机的双重工作模式：由硬件决定，由PSW标识
	程序状态字寄存器PSW：用户1，内核0

| 用户态（目态）    | 内核态（管态）                         |
| ---------- | ------------------------------- |
| 应用程序       | 内核程序                            |
| 非特权指令：数据计算 | 特权指令：启动外设、设置时钟、关中断、修改PSW（返回用户态） |
- 用户态->内核态：由中断引起，硬件工作
- 内核态->用户态：特权指令修改PSW


> 虚拟地址空间：
> 32位linux中，用户空间3GB，内核空间1GB
> x86-64位linux中，各256TB

### 2、中断和异常
> 解决用户态与内核态切换时的安全问题
> 详细定义：[异常和中断机制](408考研复习/计组原理-408/第5章%20中央处理器.md#*五、异常和中断机制)
> 工作原理：[程序中断方式](408考研复习/计组原理-408/第7章%20输入输出系统.md#程序中断方式)

广义**中断**：使 CPU强行转为内核态
- **内中断**（**异常**）
	1. 陷阱 trap（自陷、陷入）：陷入指令
	2. 故障 fault：缺页故障、用户态下执行特权指令
	3. 终止 abort：硬件故障
- **外中断**
	1. 时钟中断
	2. I/O中断
	- 可屏蔽中断 / 非屏蔽中断

### 3、系统调用
>- 程序接口由一组系统调用（system calls）组成
>- 每个系统调用都有唯一的系统调用号，每一个系统调用都是一个完成内核功能的函数
>- 系统调用向操作系统提出服务请求，由内核完成
>- 系统调用是比库函数更底层的接口

- 分类：设备管理，文件管理，进程管理，进程通信，内存管理
1. 传参：将系统调用号压入堆栈
2. 用户态下执行**访管指令/陷入指令**，用户态->系统态【PC、PSW、通用寄存器内容入栈】
3. 执行系统调用程序：通过系统调用号查找系统调用表，得到对应的**系统调用程序system_call()** 的<u>入口地址</u>；执行系统调用程序system_call()，获得服务例程类型与地址；执行系统调用服务例程fork()
4. 恢复并返回应用程序

- 整体结构：无结构，linux

	- 用户态：进程管理，存储管理，设备管理
- 外核：可以直接给用户物理内存上的资源
## 操作系统引导（开机）
ROM中存储了<u>基本输入输出系统BIOS</u>
1. CPU从ROM中读取并执行BIOS，建立中断向量表
2. BIOS的【自举程序】进行硬件自检与启动设备选择
3. 读取主引导记录MBR，执行磁盘引导程序扫描分区
4. 读取主分区中的分区引导记录PBR
5. 执行根目录下的操作系统初始化程序【启动管理器、引导程序】

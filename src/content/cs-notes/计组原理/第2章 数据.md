## 2、定点数的编码表示
>真值：带正负号的数值
>机器数：把正负号用01表示

- 机器数的定点表示：符号位+尾数【机器中没有小数点，人为约定小数点位置】
	- 定点整数
	- 定点小数【纯小数0.xxx】
- 定点数的编码表示
	1. 原码：正0负1
	2. 反码：正数反码 = 原码；负数反码 = 数值位全部取反
	3. **补码**：正数补码 = 原码；负数补码 = 反码的末位加1【进位时符号位不变】
		- 原码的真值0有两种形式，0,00与1,00，补码的真值0只有一种0,00
		- <u>整数补码（1,00）定义为-2<sup>2</sup>，小数补码（1,00）定义为-1</u>，因此整数和小数的补码的表示范围都比原码多一个数
		- 整数范围：\[-2<sup>n</sup>, 2<sup>n</sup>-1\] 
	4. **移码**：补码的符号位取反；只能用于整数，方便比较大小
		定义：真值+偏置值2<sup>n</sup>-1
<img src="images/Pasted%20image%2020260311210905.webp" width="430">
>为节省设计减法器的开支，采用模运算思想（如：(10-3) mod 12 = (10+9) mod 12）
>假设计算器字长为2<sup>8</sup>，相当于对所有数值进行mod2<sup>8</sup>运算，在进行减法时可以用加补码替代
## 3、整数的表示及C语言中的类型转换
- 无符号整数表示：eg:1111 = 2<sup>4</sup>-1
- 有符号整数表示：现代计算机用补码的优势
	1. 数值0的表示唯一
	2. 符号位可与数值位一起参与运算
	3. 表示范围多一位-2<sup>n</sup>***（注意计算时，n是否包括符号位，若包括则为-2<sup>n-1</sup>）***
- C语言整数类型：short(16位)，int(32位)，long(根据系统位数)；unsigned+int可定义无符号数
- 有符号整型用补码存储，无符号整型因节省符号位表示范围更大
- **类型转换**：
	1. 位截断：丢弃高位
	2. 位扩展：填充高位，数值不变
		- 零扩展：无符号数，直接填0
		- 符号扩展：有符号数，在高位重复填符号位
	3. unsigned转换：不改变二进制值，但是改变了符号位导致数值变化

	- ZF(zero flag)：零标志 1为零 0不为0
	- OF(overflow flag)：溢出标志（**有符号数加减**） 1溢出 0未
		- 加法：
			1. 正 + 正，算出负数 → 溢出 OF=1
			2. 负 + 负，算出正数 → 溢出 OF=1
			3. 一正一负相加，永远不会溢出 OF=0
		- 减法：转换为加法，A-B=A-(-B)【被减数取反+1】
	- SF(signal flag)：符号标志 1负 0正
	- CF(carry flag)：进位错位标志（**无符号数加减**） 1溢出 0未
		- 加法：两无符号数相加超出位数最大值 → CF=1
			减法：被减数 < 减数（无符号比较）→ CF=1

### **算术逻辑单元ALU**
<img src="images/QQ_1782201271141.webp" width="400">
- 如果ALU支持k种功能，则控制信号位数m ≥\[log² k]
- ALU的运算数、运算结果位数与计算机的机器字长相同
- ZF/OF/SF/CF标志位，用于表示本次运算结果的特征
	- ZF-运算结果是否为零
	- OF-有符号数运算结果是否溢出
	- SF-有符号数运算结果的正负性
	- CF-无符号数运算结果是否溢出
- 这些标志信息通常会被送入PSW程序状态字寄存器【有的计算机系统把PSW寄存器称为“标志寄存器FR（Flag Register）”
- Cin是进位输入信号、Cout是进位输出信号（类似于带标志位的加法器）
## 2、定点数的移位运算
1. 逻辑移位（无符号）
	- 左移：高位移出，低位补0，高位的1移出时，发生**溢出**
	- 右移：低位移出，高位补0
2. 算术移位（带符号）
	- 左移：高位移出，低位补0，高位的符号位改变时，发生**溢出**
	- 右移：低位移出，高位补符号位，右移会丢失精度（1100——>1110)
## 3、定点数的加减
### 补码加减运算
\[ X + Y ]补 = \[X]补+\[Y]补
\[ X - Y ]补 = \[X]补+\[ -Y ]补
- 符号位也参与运算
- 运算结果自动截断 mod 2<sup>n+1</sup>
	><img src="images/Pasted%20image%2020260315211327.webp" width="236">
### 溢出判别
1. 单一位符号位判别： $V = A_S B_S \overline{S_S} + \overline{A_S} \overline{B_S} {S_S}$
	V=0，无溢出；V=1，溢出
2. 一位符号位结合进位： V= C<sub>n</sub> xor C<sub>n-1</sub>
	V=0，无溢出
3. 双符号位：V = S<sub>s1</sub> xor S<sub>s2</sub>
	V=0，无溢出
>双符号补码：模4补码（*单符号模2*）正00负11，实际只存储一位，运算时复制一位，不占空间

# 三、浮点数的表示与运算
## 1、IEEE 754标准浮点数
### 单精度与双精度
32位单精度浮点数（float）: 符号1，阶码8，尾数23
64位双精度浮点数（double）符号1，阶码11，尾数52
- 符号位：0正1负
- 阶码：用移码表示，单精度偏置值为127，双精度偏置值为1023（2+127 = 10000001）
- 尾数：小数点前恒为1省略
>-8.25 = -1000.01 =-1.00001x 2<sup>3</sup>= 1 10000010 0000 1000 0000 ...
### 规格化浮点数
阶码不全为0、1
- 阶码(1~254)的真值(-126~127)
- 规格化浮点数的表示范围： (+/-) 1x2<sup>-126</sup> ~ (2-2<sup>-23</sup>)x2<sup>127</sup>
<img src="images/Pasted%20image%2020260321192852.webp" width="650">
### 浮点数的上溢（overflow）下溢（underflow）
- 上溢：设置为无穷，设置溢出异常标志位，但默认不响应
- 下溢：设置为0 / 非规格浮点数，设置下溢异常标志位，默认不响应
	<img src="images/Pasted%20image%2020260321205545.webp" width="560">
## 2、浮点数的加减运算
1. 对阶：小阶向大阶靠齐（阶码小的进行移位）
2. 尾数加减：原码加减
3. 尾数规格化
	- 0.001 -- 左规 -- 阶码-1
	- 111.001 -- 右规 -- 阶码+1
4. 舍入：**就近舍入**（IEEE默认）
	【0舍1入】
	- 0 | 0xx —— 截断
	- 0 | 1xx —— 进1
	🔺特殊情况：**0 | 100 —— 截断**
5. 溢出判断：**通过阶码判断**
	<img src="images/Pasted%20image%2020260609184043.webp" width="610">
	- 上溢：阶码全1，尾数全0 —— 表示无穷；若符号为正则称为‘正上溢’
	- 下溢：阶码全0，若尾数不为全0，即表示为**非规格化数**；若尾数全0，即数零
		
	>**当计算出现非规格化浮点数时：**
	>尾数左规时，阶码已经减到全0，说明发生下溢，
	>此时直接得到结果=最小值2<sup>-126</sup> \* (尾数部分) = 2<sup>-149</sup>
	><img src="images/Pasted%20image%2020260321215617.webp" width="460">

> 上下溢异常一般不响应，不中断程序

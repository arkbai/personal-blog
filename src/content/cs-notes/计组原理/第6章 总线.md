# 一、概述
> 总线（Bus）是一组为多个部件分时共享的公共信息传送线路，每个总线包含多根信号线

### 总线的特性
1. 机械特性：尺寸、形状、管脚、排列
2. 电器特性：传输方向、电平有效范围
3. 功能特性：地址/数据/控制信号
4. 时间特性：信号的时序关系

### 总线的分类
1. 按数据传输格式：
	- 串行总线：（如USB）只有一条传输线，1bit，成本低，长距离传输，发送接收时需要进行数据的拆卸与装配
	- 并行总线：成本高，信号线直接会产生干扰，工作频率较低
> 并行总线的工作频率无法一直提高，串行总线可以通过提高工作频率来提高传输速度
2. 按总线功能：
	- 片内总线：芯片内部寄存器、ALU之间的公共线
	- **系统总线**：CPU、主存、I/O接口之间的总线；
		根据传输信息不同分为：
		- **数据总线DB**：传输各部件的数据（指令、操作数），位数与机器字长，存储字长有关；双向
		- **地址总线AB**：传输地址信息（主存单元、I/O端口地址），位数与主存地址空间大小有关；单向
		- **控制总线CB**：控制信息（cpu控制命令、主存返回cpu的反馈信号）
	- 通信总线：外部总线，计算机系统之间，计算机系统与其他系统之间
3. 按时序控制方式：
	- 同步总线
	- 异步总线

### 系统总线的结构
1. 单总线结构：简单，带宽低
2. 双总线结构：主存总线（cpu、主存、通道）+ I/O总线（外部设备与通道之间）
	- 添加[I/O通道](408考研复习/操作系统-408/第4章%20设备管理.md#I/O通道)来管理I/O设备，将慢速的I/O设备分离出来
3. 三总线结构：主存总线+I/O总线+**DMA总线**
	- 直接内存访问DMA：使高速I/O设备通过DMA传输数据
	- 同时只能有一个总线工作，总体效率较低
4. 四总线结构：cpu总线+系统总线+高速总线+扩充总线
	- 添加**桥接器**来连接不同总线，进行数据的缓冲、转换、控制（南桥、北桥）
	- 靠近cpu的总线块

### 总线的性能指标
1. 总线的总线周期（传输周期）：一次总线操作的时间（申请、寻址、传输、结束）
2. 总线时钟周期：= 机器时钟周期
	- 总线周期----时钟周期——1对n、n对1、n对n都有可能
	- eg:每个时钟周期传送2次数据——总线工作频率 = 2x总线时钟频率
3. 总线工作频率：1 / 总线周期
4. 总线时钟频率：1/ 总线时钟周期
5. 总线宽度（总线位宽）：数据总线根数，如32bit表示32根数据总线
6. 总线带宽：单位时间**最大**传送字节数，B/s或bit/s
	- 总线带宽 = 总线工作频率 x 总线宽度
7. 总线复用：如地址&数据总线复用，同一根线在不同时间起到不同作用
8. 信号线数：地址、数据、控制总线的总和

# 二、总线事务与定时
> 占用了总线的一对设备，如何相互传输数据

总线周期的四个阶段
1. 申请分配阶段：传输请求+总线仲裁
2. 寻址阶段：主模块进行寻址
3. 传输阶段：主模块与从模块进行数据交换
4. 结束阶段：总线上的有关信息清除，让出总线

### 总线定时
> 总线双方在数据交换中的时间配合，协议

1. 同步通信（同步定时方式）：由统一时钟控制
	- 优点：传输速度快，传输效率高；总线逻辑简单
	- 缺点：主从设备属于强制同步，不能及时地进行数据检验，可靠性差
	<img src="images/QQ_1784171848267.webp" width="750">
	- 局限-如果在要求的时钟沿没有完成对应操作，就会产生错误
2. 异步通信：采用应答方式，主设备发出‘请求’信号，从设备发出‘回答’信号
	- 优点：总线周期长度可变，可以让两个工作速度差别较大的设备之间进行可靠的数据交换
	- 缺点：比同步较复杂，速度较慢
	1. 不互锁：一段时间后，双方自动撤销信号
	2. 半互锁：主设备在发出‘请求’后，必须收到‘回答’才会撤销‘请求’信号；从设备则是过一段时间后自动撤销
	3. 全互锁：主从设备互锁   
3. 半同步通信：结合同步异步，在统一时钟基础上，加一个等待信号WAIT

4. 分离式通信：一个传输周期中间存在空闲，将一个周期分为两个子周期，从而提高总线利用率⤵

	2. 从模块申请占用总线，放弃

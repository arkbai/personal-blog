3. 定点机器数的表示方法
    - 原码  0正1负
    - 补码  0正，1负取反后+1
        
        100000…表示-2^n 和 -1
        
    - 反码  0正，1负取反
    - 移码  1正， 0负取反后+1
        
        只用来表示定点整数，只有移码可以直接比较
        
4. 浮点机器数的表示方法
    
    数符M + 阶码E + 尾数M
    

**规格化表示**

- 位数不足的，尾数在后面补0，阶码在前面补0
- 原码表示尾数 当最高位为0时，进行左规，直至尾数变为x.1xxxx形式
    
    补码表示尾数 当符号位与最高有效位相同时，进行左规，直至变为0.1xxxx或1.0xxxxx
    
- 尾数发生溢出时，进行右规

***（P79）***

单精度：**总位数32 = 数符Ms 1位，阶码E 8位，尾数M 23位**

±无穷大：阶码全1，尾数全0

NaN：阶码全1，尾数不全0

## 5. 存储系统

1. 概述
    
    一般存储器靠**地址**访存
    
    分类：
    
    - 按存储介质分：半导体/磁
    - 按存取方式分类：随机存储器RAM，只读存储器ROM，相联存储器CAM
    - 按作用分：寄存器，高速缓存，主存储器，辅助存储器(外存）
    
    存储器的性能指标：
    
    - 存储容量：64K x 16位
        
        → 地址线 10+6 =16 根 ｜数据线 16根
        
        **存储单元**是最小的可编址单元，每个单元1bit
        
        字节 = 8bit
        
        字长 表示cpu一次处理长度，决定计算机“字”的大小
        
        字 由字节组成 （64位系统中，1字 = 64位 = 8字节）
        
    - 存储时间，存储周期
    - 带宽，转速
    
    存储器的层次结构：
    
    寄存器——高速缓存——主存——本地外存——网络存储器
    
2. 主存储器
    
    SRAM 静态随机存储器    6MOS管
    
    DRAM 动态随机存储器    2电容
    
    **DRAM的刷新**：
    
    1）集中式刷新
    
    在一个刷新周期中，利用一段时间对所有行逐一刷新→**死区**
    
    设 2048列，存储周期500ns，刷新周期64ms 则访存周期 = 64ms / 500ns 死区 = 2048*500ns
    
    2）分散式刷新
    
    存储周期翻倍，延长了运算时间
    
    3）异步式刷新
    
    分散地刷新各行，避免多次刷新，缩短了死区
    
    SDRAM 同步动态随机存储器 DDR SDRAM 双倍数据效率…
    
    ROM 只读存储器
